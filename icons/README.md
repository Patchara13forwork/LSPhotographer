# ไอคอนของเว็บ

เว็บมีไอคอน 2 แบบ

## 1. ไอคอน UI (ไฟล์ในโฟลเดอร์นี้)

ใช้กับปุ่มและเมนู เช่น ค้นหา, เฟืองตั้งค่า, ลูกโลก, หยุด/เล่น, ลูกศร
ไฟล์ SVG ถูกใช้เป็น "mask" ใน `index.html` แล้วระบายสีด้วย CSS จึงเปลี่ยนสีตาม CI และโหมดมืด/สว่างเอง

**เปลี่ยนเป็นไอคอนจาก Magnific (เดิมคือ Freepik):**
1. ดาวน์โหลดไอคอน **SVG ชนิดเส้น (line / outline) สีเดียว** จาก https://www.magnific.com/icons
2. ตั้งชื่อไฟล์ให้ตรงกับไฟล์เดิม เช่น `search.svg`, `settings.svg` แล้ววางทับในโฟลเดอร์นี้
3. ไม่ต้องแก้โค้ด

## 2. ไอคอนประจำเนื้อหา (อยู่ใน `index.html` โดยตรง)

ใช้ในส่วนประเภทภาพ, เกี่ยวกับเรา, กำหนดการ และที่ตั้ง เป็น SVG แบบ 2 สี
(เส้นขาวบนกล่องดำ + จุดเน้นแดง) และมี animation วาดเส้นตอนเลื่อนถึง
ต้องเขียนเป็น SVG ในหน้าเว็บโดยตรงเพราะใช้ 2 สีและ animation ได้

ถ้าจะเปลี่ยนเป็นไอคอนจาก Magnific ให้แทนที่แท็ก `<svg>` ใน `<span class="ficon">` ตัวนั้น
- เส้นหลักใส่ `class="s" pathLength="1"` (จะวาดตัวเองตอนเลื่อนถึง)
- ส่วนที่ต้องการให้เป็นสีแดงใส่ `class="a"`

## เรื่องลิขสิทธิ์

ไอคอนฟรีของ Magnific ต้องใส่เครดิตผู้สร้าง (สมาชิก Premium ไม่ต้องใส่)
ให้เพิ่มข้อความเครดิตตามที่หน้าดาวน์โหลดกำหนดไว้ที่ส่วน footer ของ `index.html`

ไอคอนชุดปัจจุบันวาดขึ้นใหม่สำหรับเว็บนี้ ใช้ได้โดยไม่ต้องใส่เครดิต
