# ไอคอนของเว็บ

ไอคอนทุกตัวในโฟลเดอร์นี้ถูกใช้เป็น "mask" ใน `index.html` แล้วระบายสีด้วย CSS
จึงเปลี่ยนสีตาม CI ดำ-แดง และโหมดมืด/สว่างได้อัตโนมัติ ไม่ต้องแก้สีในไฟล์ SVG

## เปลี่ยนเป็นไอคอนจาก Magnific (เดิมคือ Freepik)

1. ดาวน์โหลดไอคอนแบบ **SVG ชนิดเส้น (line / outline) สีเดียว** จาก https://www.magnific.com/icons
2. เปลี่ยนชื่อไฟล์ให้ตรงกับไฟล์เดิม เช่น `portrait.svg`, `camera.svg` แล้ววางทับในโฟลเดอร์นี้
3. ไม่ต้องแก้โค้ด — เว็บจะใช้ไฟล์ใหม่ทันที

**เรื่องลิขสิทธิ์:** ไอคอนฟรีของ Magnific ต้องใส่เครดิตผู้สร้าง (ถ้าเป็นสมาชิก Premium ไม่ต้องใส่)
ให้เพิ่มข้อความเครดิตตามที่หน้าดาวน์โหลดกำหนดไว้ที่ส่วน footer ของ `index.html`

ไอคอนชุดปัจจุบันวาดขึ้นใหม่สำหรับเว็บนี้ (viewBox 24×24, เส้นหนา 1.75) ใช้ได้โดยไม่ต้องใส่เครดิต
